Prusa Research writes these extensions and keeps them in the server's own repository, under `extensions/`. Each one is versioned and released on its own, apart from the server.

There are three ways to get one:

- **The Extensions page.** Settings, Extensions lists the extensions on the Prusa marketplace and installs one with one click. The install dialog shows what the extension asks for before anything runs. [Extensions in the configuration](../../config/extensions.md) says how to turn the listing off or point it at a marketplace of your own.
- **The container image.** The image carries every extension below under `/opt/modules`. Name the ones you want in `core.modules_local`, and the Extensions page offers them. [Container deployment](../../container.md#bundled-extensions) has the lines to copy.
- **The command line.** `prusa-connect module add <module path>@<version> -from <release directory>` installs a release you built or downloaded. Without `-approve` it writes the extension switched off and prints what it asks for.

Each page below says what the extension adds to the app, what it needs from the server, its settings and its routes. That part is generated from the extension's `module.yaml` and `openapi.json`, so it always matches the release in this repository. The extension's README under `extensions/<folder>/` has the details a developer needs.

## The extensions {#the-extensions}

- **[Prusa printer logs](./buddy-debug-logs.md)** 0.1.10. Keeps the log lines and metrics your Prusa printers send, for a day, and adds them to the diagnostics bundle.
- **[Fleet stats](./fleet-stats.md)** 0.3.4. Job KPIs, a daily trend, the most printed files, a utilization heatmap and failures for the fleet, with dashboard cards.
- **[Materials](./materials.md)** 0.2.7. A catalogue of filament materials, and the spools a person has of them.
- **[Parts](./parts.md)** 0.3.8. A private catalogue of parts, with folders, versions of their files, comments and printing.
- **[Server slicing](./server-slicing.md)** 0.2.3. Slices 3MF projects into G-code on this server with the PrusaSlicer command line, and writes the G-code into a storage.
- **[3MF projects](./threemf.md)** 0.1.12. Shows a 3MF project on the page of its file, with its beds, objects and settings, and reads 3MF files for the server.
